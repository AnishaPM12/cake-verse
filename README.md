# 🍰 CakeVerse – Online Cake Ordering Website

## 📌 Project Overview

**CakeVerse** is a modern and visually appealing online cake ordering website developed as an HTML mini project. The website is designed to provide users with a simple and attractive platform to explore different varieties of cakes and discover cakes suitable for different occasions.

The website focuses on creating a pleasant user experience through an aesthetic interface, organized cake categories, product cards, navigation options, and interactive shopping features. Users can browse cakes, view product details, add cakes to their cart, manage their wishlist, explore special offers, customize cakes, and track their orders.

CakeVerse is designed with a bakery and celebration theme, making it suitable for birthdays, weddings, anniversaries, and other special occasions.

---

## 🎯 Objectives

The main objectives of the CakeVerse project are:

* To design an attractive and user-friendly cake ordering website.
* To provide users with an easy way to browse different cake categories.
* To showcase popular and best-selling cakes.
* To provide options for customizing cakes.
* To implement basic shopping features such as cart and wishlist.
* To display special offers and delivery information.
* To provide an order tracking option.
* To practice frontend web development concepts using HTML, CSS, and JavaScript.

---

## ✨ Features

### 🏠 Home Page

The home page provides an attractive introduction to CakeVerse with a hero section displaying the website's main theme, promotional content, and options such as **Shop Now** and **Customize Cake**.

### 🎂 Cake Categories

Users can explore cakes based on different occasions and preferences, including:

* Birthday Cakes
* Wedding Cakes
* Anniversary Cakes
* Cup Cakes

The category section makes it easier for users to find cakes according to their requirements.

### ⭐ Best-Selling Cakes

CakeVerse includes a **Best Selling Cakes** section that displays popular customer-favourite cakes.

Some of the featured cakes include:

* Chocolate Truffle
* Red Velvet Cake
* Black Forest Cake
* Blueberry Cake

Each product includes a cake image, rating, price, wishlist option, and **Add To Cart** button.

### ❤️ Wishlist

Users can use the heart icon provided on cake products to mark cakes as favourites and easily identify products they are interested in.

### 🛒 Shopping Cart

The website provides a shopping cart feature where users can add their selected cakes. A cart counter is also included in the navigation bar to indicate the number of items added.

### 🎨 Custom Cakes

CakeVerse provides a **Custom Cakes** section that allows users to explore the option of creating cakes according to their preferences.

### 🎉 Special Offers

The website highlights special promotions to attract customers. For example, the homepage displays an offer of **40% OFF on Birthday Cakes** and free delivery for orders above **₹999**.

### 🚚 Same-Day Delivery

The website highlights same-day delivery as one of its service features, making the platform suitable for users who need cakes for special occasions at short notice.

### 📦 Order Tracking

A **Track Order** option is provided so that users can access the order tracking section.

### 🔍 Search

The navigation bar contains a cake search field that allows users to search for cakes.

### 👤 Login

A user icon is included in the navigation area for accessing the login section.

### 📞 Contact & Help

CakeVerse includes navigation options for **Contact** and **Help**, making it easier for users to access support-related information.

## 🛠️ Technologies Used

The project is developed using frontend web technologies:

* **HTML5** – Used to create the structure and content of the webpages.
* **CSS3** – Used for styling, layouts, colors, spacing, and overall visual appearance.
* **JavaScript** – Used to add interactive functionality to the website.
* **Font Awesome** – Used for icons throughout the interface.
* **Google Fonts** – Used to improve the typography and visual appearance.

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Open the project folder.
3. Make sure all HTML, CSS, JavaScript, and image files are present in the correct locations.
4. Open `index.html` in a web browser.
5. Navigate through the different sections of CakeVerse.

No additional installation is required for the basic frontend website.
